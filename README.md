## Getting Started
1. Fork this repository
2. Solve all 5 mandatory HackerRank problems
3. Create solution files in your preferred language (C++, Java, or Python)
4. Document each problem with:
   - Problem statement link
   - Time complexity analysis
   - Space complexity analysis
   - Approach explanation
5. Achieve 3-Star badge on HackerRank
6. Update your public profile link
7. Submit via the studio activity portal
